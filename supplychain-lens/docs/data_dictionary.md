# Data dictionary — SupplyChain Lens (nexus_v2)

Generated by `python -m supplychain_lens.data.dictionary` from the actual Parquet files.
**All data is synthetic**, produced by `supplychain_lens/data/generator.py` from the NEXUS-SCCT data model.

**Origin:** *Original* = same as NEXUS-SCCT · *Fixed* = NEXUS field regenerated to remove a defect (D1–D10, see `docs/feature_audit.md`) · *Extension* = new · *Derived* = computed by the simulation · *Truth* = hidden, evaluation only.

Calendar 2023-01-01 → 2025-12-31 · snapshot 2025-12-31 · split: train ≤ 2025-06-30, validation ≤ 2025-09-30, test = Q4 2025.
